# Parallax for Copilot

**Hands-off coding for GitHub Copilot. Reviewed plans, clean-context execution, independent audits.**

Say what you want in one sentence. Parallax turns it into a discussion you steer with a few choices, then an approved plan, an independent plan review, a clean-context execution session and an independent reconciliation review — driven through GitHub Copilot Chat in VS Code.

This extension bundles the Parallax skills; the suite and its documentation live at **github.com/AI4XE/Parallax**.

## Three steps

Plugin trigger words: **wish · Parallax · qstart**

- **Wish** — say what you would like, as casually as you like. You do not need to have it figured out; add more in several messages and say "that's all" when you are done.
- **Choose** — the agent researches first, then aligns with you one question at a time; you just pick.
- **Hand off** — the agent team takes it from there: plan → independent review → new-session execution → independent audit → scoped commit → wrap-up.

> After installing, reload the window when VS Code offers it, so Copilot picks up the skills.
